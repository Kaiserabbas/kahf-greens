# Balcony Gallery Images

Add your balcony images here in any of these formats:
- `.jpg` / `.jpeg`
- `.png`
- `.gif`
- `.webp`
- `.avif`

## How to add images:

1. Place image files directly in this folder
2. The gallery will automatically load and display them in a Pinterest-style masonry layout
3. Images are lazy-loaded for better performance
4. Click any image to view it in fullscreen

## Supported formats:

- JPEG (recommended for photos)
- PNG (for images with transparency)
- WebP (modern format, better compression)
- AVIF (next-gen format, smallest file size)

## Tips:

- Use descriptive filenames
- Optimize images for web (72-96 DPI, 2-3MB max)
- The gallery displays all images automatically - no manual configuration needed
